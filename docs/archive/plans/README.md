# PLAN 快照

> 类型：历史

每个主干完成或暂停切走时，把当时的 `docs/PLAN.md` 复制到这里，命名：

```text
TRUNK-<编号>-<YYYYMMDD>.md
```

例：`TRUNK-2-20261115.md`。

快照只读；后续变化写进新的 `PLAN.md` 和 `STATUS.md`，不回改快照。
